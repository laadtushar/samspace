# Anger reel pack (marketing media)

Full-quality masters of the reels made from Priyanka's 23 Oct talk, with covers,
stills, subtitles, captions and the audit. This branch holds media only: it shares
no history with `main`, and `vercel.json` here turns off deployments for it.

- `reels/` — five 1080×1920 30 fps masters (H.264/AAC, −13 LUFS)
- `covers/` — one cover per reel
- `stills/` — carousel (7), quote posts (2), Stories (3)
- `subtitles/` — `.en.srt` and `.hi.srt` per reel
- `MARKETING-KIT.md` — captions, hooks, hashtags, posting plan; `AUDIT.md` — checks
- `run-skill-generator.zip` — the skill that produced all of this

The same files (the full reel as a smaller copy) are on the download page:
